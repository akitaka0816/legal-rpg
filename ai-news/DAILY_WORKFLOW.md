# 毎日のニュース更新手順(パターン①: Claude Code 運用)

## 朝のルーティン(所要時間 3〜5分)

### Step 1: Claude Code を起動
- ブラウザで [Claude.ai/code](https://claude.ai/code) を開く、または VS Code拡張・CLI のいずれか
- `legal-rpg` リポジトリを開く

### Step 2: スラッシュコマンドを実行
チャット欄に以下を入力するだけ:

```
/daily-news
```

これだけで、Claude が以下を自動実行します:
1. 過去24〜48時間のAI関連ニュースをWebSearchで収集(5カテゴリ並列)
2. 法務観点で記事を選別(8〜15件)
3. 法務向けの要約 + カテゴリ自動付与
4. `ai-news/data/articles.json` を更新(10日経過した記事は自動削除)
5. git commit & push
6. 完了報告(追加件数・カテゴリ内訳・ハイライト)

### Step 3: ダッシュボードを確認
2〜3分後、以下にアクセス:
👉 **https://akitaka0816.github.io/legal-rpg/ai-news/**

### Step 4(任意): Slackに共有
気になる記事があったら、もう一言指示:

```
今追加した中から重要な3本を選んで、
Slack投稿用の短いまとめを150字以内で作って
```

## バリエーション指示

### 重点トピックを指定
```
/daily-news EU AI Actの動向を重点的に
```

```
/daily-news 契約書レビューに関わる実務記事だけ
```

```
/daily-news 海外規制(米国・英国・EU)を厚めに
```

### 件数を絞る
```
/daily-news 重要なものだけ5件で
```

### 特定カテゴリを除外
```
/daily-news 技術トレンドは除いて、ガバナンスとリスク中心
```

`/daily-news` の後ろに自然言語で書くと、Claude が解釈して実行します。

## トラブルシュート

**Q. push に失敗する**
→ 別の人が直前に編集している可能性。`git pull origin main` してから再実行を依頼。

**Q. 同じ記事が何度も追加される**
→ Claudeに「既存記事との重複チェックをもっと厳しく」と追加指示。

**Q. ノイズ記事が混ざる**
→ 「次回からは公的機関と大手メディアの記事だけにして」と指示すれば次回以降は厳格化される。常時厳格にしたい場合は `.claude/commands/daily-news.md` の選別基準を編集。

**Q. ダッシュボードに反映されない**
→ GitHub Actions の `pages-build-deployment` ワークフローが走っているか Actions タブで確認。通常2〜3分で反映。

---

## 不在時の運用

旅行・休暇等で数日できない場合:
- 戻った日に `/daily-news 過去3日分の重要ニュースをまとめて` と指示
- 10日以上空くと古い記事が自動削除されるため、空白期間が出る点だけ留意

---

## カスタマイズ

選別基準・カテゴリ・要約スタイルを変えたい場合は、`.claude/commands/daily-news.md` を直接編集してください。Claudeは毎回このファイルを参照して動きます。

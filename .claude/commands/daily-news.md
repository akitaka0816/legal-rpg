# 法務部AIニュース ── 日次更新タスク

法務部員向けに、過去24〜48時間のAI関連ニュースを収集して `ai-news/data/articles.json` を更新する。

## ユーザー指示(任意)

$ARGUMENTS

(空の場合は通常運用。指示がある場合は重点トピックや件数希望として尊重する)

## 実施手順

### 1. 現在のデータを確認
- `ai-news/data/articles.json` を読み、既に登録済みの記事URL/タイトルをチェック(重複回避のため)
- `generated_at` を確認し、前回更新からの差分期間を把握

### 2. ニュース収集(WebSearch を並列実行)
以下5カテゴリを並列で検索する。検索クエリには **今日の日付の年月** を含めて鮮度を担保:

| カテゴリ | 検索クエリ例 |
|---|---|
| ガバナンス | `AI 規制 ガイドライン 法務 [当月]` `EU AI Act enforcement [当月]` `個人情報保護法 AI [当月]` |
| 利活用 | `生成AI 企業 導入事例 [当月]` `リーガルテック 契約書 [当月]` |
| 事業戦略 | `AI 投資 提携 買収 [当月]` `OpenAI Anthropic 提携 [当月]` |
| 技術トレンド | `Claude Gemini GPT 新モデル 発表 [当月]` |
| リスク・インシデント | `AI 情報漏洩 訴訟 著作権 [当月]` `AIエージェント インシデント [当月]` |

### 3. 記事の選別基準
**採用する記事:**
- 法務部員が実務に活かせる(規制動向・判例・ガイドライン・実装事例)
- 公的機関・大手メディア・著名な弁護士事務所・上場企業のリリース
- 過去48時間以内のニュースを優先(古くても重要な解説記事は可)

**除外する記事:**
- アフィリエイト・SEO目的の「おすすめ◯選」「比較ランキング」
- 個人ブログの主観的論評(法律事務所・専門家のものは可)
- 既に登録済みの記事(タイトル類似度をチェック)
- 内容が薄い速報や告知だけのもの

目安: **8〜15件** を新規追加。

### 4. JSON更新
`ai-news/data/articles.json` に追記する。各記事のフィールド:

```json
{
  "id": "YYYYMMDD_NNN",
  "title": "記事タイトル(原文ママ)",
  "url": "https://...",
  "source": "媒体名",
  "summary": "2〜3文。事実関係 + 法務観点の論点を1文添える。最大400字。",
  "published_at": "YYYY-MM-DDTHH:MM:SS+00:00",
  "categories": ["主カテゴリ", "副カテゴリ(任意)"]
}
```

**カテゴリ判定ルール(複数可):**
- 規制・法令・ガイドライン・行政発表 → `ガバナンス`
- 業務導入・ユースケース・PoC事例 → `利活用`
- M&A・提携・出資・市場動向 → `事業戦略`
- 新モデル・新機能・性能比較 → `技術トレンド`
- 訴訟・漏洩・脆弱性・誤動作・バイアス → `リスク・インシデント`

### 5. 10日以上前の記事を削除
`published_at` が今日から10日以上前の記事は配列から除外する。

### 6. メタデータ更新
- `generated_at`: 現在時刻(UTC, ISO8601)
- `article_count`: `articles` 配列の長さ

### 7. コミット&プッシュ
```bash
git add ai-news/data/articles.json
git commit -m "data(ai-news): daily update YYYY-MM-DD (N件追加, 累計M件)"
git push origin main
```

(現在のブランチが main 以外なら、まず `git checkout main && git pull` してから作業)

### 8. 完了報告
ユーザーに以下を簡潔に伝える:
- 追加した記事数と総数
- カテゴリ別の内訳
- 特に注目すべき1〜2本のハイライト(タイトル+一言コメント)
- ダッシュボードURL: `https://akitaka0816.github.io/legal-rpg/ai-news/`

## 注意事項

- **WebSearch は並列で**(同一メッセージ内で複数tool callを並べる)実行して時間短縮
- URLが本物であることを保証する(WebSearch結果に出てきたものだけを使う、捏造禁止)
- 公開済みダッシュボードに影響するため、JSONの構文エラーに注意(コミット前に `python3 -c "import json; json.load(open('ai-news/data/articles.json'))"` で検証)
- 重要案件(罰金・刑事事件・大型M&A等)は `summary` に法務観点をしっかり書く
